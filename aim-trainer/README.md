# باشگاه تمرین Aim (Aim Trainer)

یک ابزار **کاملاً آفلاین** برای تمرین نشانهگیری: فلیک، تعویض هدف و ردیابی.
هدفش اینه که مهارت دست خودت رو بسازه، نه اینکه تو بازی دخالت کنه.

## این چی **نیست**

- ❌ هیچ ارتباطی با Call of Duty Mobile (یا هر بازی دیگه) نداره: نه APK میخونه، نه پروسس، نه حافظه، نه پکت شبکه، نه حساب کاربری.
- ❌ هیچ inject / hook / patch / overlayـه روی بازی انجام نمیده.
- ❌ چیت، aim-assist، aimbot، no-recoil یا ابزار دور زدن آنتیچیت نیست.
- ❌ هیچ چیزی رو از گوشی یا مرورگر بیرون نمیفرسته؛ آمار فقط تو `localStorage` همین مرورگر ذخیره میشه.

## راه اندازی

سادهترین راه: `index.html` رو مستقیم تو مرورگر باز کن (حتی آفلاین کار میکنه).

یا یه سرور محلی:

```bash
cd aim-trainer
python3 -m http.server 8000 --bind 0.0.0.0
```

بعد برو `http://localhost:8000`. تو موبایل هم باز میشه (رابط RTL و لمسیه)،
کافیه گوشی و کامپیوتر تو یه شبکه باشن و از IP محلی استفاده کنی.

## حالت‌ها

| حالت | تمرین | معیار |
|---|---|---|
| **فلیک** | یه هدف تصادفی، سریع بزن تا بعدی بیاد | زمان واکنش (ms) + دقت |
| **Grid** | ۵ هدف همزمان، جابجایی سریع بینشون | برخورد/خطا + استریک |
| **ردیابی** | هدف متحرک، انگشت/موس رو روش نگه دار | درصد زمان روی هدف |

تنظیمات: مدت ست (۱۵/۳۰/۶۰ ثانیه) و اندازه هدف (۱۸–۶۴ پیکسل).
کلیدها: `Space` = شروع، `Esc` = پایان ست.

## آمار و پیشرفت

هر ست اینا رو ذخیره میکنه: برخورد، خطا، دقت، میانگین واکنش، بهترین استریک و امتیاز.
جدول ۸ جلسهٔ آخر + نمودار ۱۲ ست آخر نشون داده میشه و دکمهٔ «خروجی CSV» کل تاریخچه رو میده.
پاک کردنش: `localStorage.removeItem('aimtrainer.history.v1')` تو کنسول مرورگر.

## روتین ۱۰ دقیقه‌ای

1. دو ست فلیک برای گرم کردن — **اول دقت، بعد سرعت** (زیر ۸۵٪ آرومتر بزن).
2. دو ست Grid برای جابجایی هدف (پرکاربردترین مهارت تو مولتی).
3. یک ست Tracking برای ثبات دست حین اسپری.
4. پیشرفت رو با جدول مقایسه کن، نه با نتیجهٔ یه مسابقه.
